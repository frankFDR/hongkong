## 三、运行爬虫

```bash
cd /root/port_news_crawler
source .venv/bin/activate

# 跑一轮全站（9 个站点，由 crawl_once.sh 逐站执行，省内存）
/root/port_news_crawler/crawl_once.sh

# 只跑单个站点
python run.py --once --site hk_marine_dept
python run.py --once --site manifold_times
python run.py --once --site hket
python run.py --once --site scmp
python run.py --once --site cnn
python run.py --once --site reuters
python run.py --once --site afp
python run.py --once --site people_daily
python run.py --once --site takungpao

# 与 cron 相同的脚本
/root/port_news_crawler/crawl_once.sh

# 后台运行（不占当前终端）
nohup /root/port_news_crawler/crawl_once.sh &
```

**说明：** 第一次全站可能需 30 分钟～1 小时；脚本输出写入 `logs/cron.log`，前台可能看起来“无反应”。

## 四、定时任务 cron

```bash
crontab -l                   # 查看定时任务
crontab -e                   # 编辑（选 nano，末尾加一行）

systemctl status cron        # 查看 cron 服务
systemctl start cron         # 启动
systemctl enable cron        # 开机自启
```

**当前推荐配置（每天 0:00 和 12:00 各跑一轮，逐站去重）：**

```cron
0 0,12 * * * /root/port_news_crawler/crawl_once.sh
```

| 表达式 | 含义 |
|--------|------|
| `0 0,12 * * *` | 每天 0:00、12:00 |
| `0 */12 * * *` | 同上（等价写法） |
| `0 8,20 * * *` | 每天 8:00、20:00（可选） |

### 查看数据

```bash
ls /root/port_news_crawler/data/articles/

# 总篇数
find /root/port_news_crawler/data/articles -name "*.json" | wc -l

# 按站点统计
for s in hket manifold_times hk_marine_dept scmp cnn reuters afp people_daily takungpao; do
  echo -n "$s: "
  find /root/port_news_crawler/data/articles/$s -name "*.json" 2>/dev/null | wc -l
done

# 查看单篇文章
cat /root/port_news_crawler/data/articles/manifold_times/2026-06-02/xxxx.json

# 最近 1 天内的文章
find /root/port_news_crawler/data/articles -name "*.json" -mtime -1
```

### JSON 字段说明

| 字段 | 含义 |
|------|------|
| `title` | 题目 |
| `text` | 正文 |
| `published` | 发布时间戳 |
| `url` | 原文链接 |
| `site` | 站点 ID |
| `fetched_at` | 抓取时间 |

## 九、配置与脚本

```bash
chmod +x /root/port_news_crawler/crawl_once.sh
ls -l /root/port_news_crawler/crawl_once.sh

nano /root/port_news_crawler/crawl_once.sh
nano /root/port_news_crawler/config.yaml
```

**`crawl_once.sh` 参考内容：**

```bash
#!/bin/bash
cd /root/port_news_crawler
source .venv/bin/activate
mkdir -p logs
python run.py --once >> logs/cron.log 2>&1
```

**`config.yaml` 常用项：**

| 配置项 | 说明 |
|--------|------|
| `headless: true` | 无界面 Chrome |
| `use_undetected: true` | 反爬（国际站）；政府站可试 `false` |
| `max_new_articles_per_cycle: 25` | 每站每轮最多新文章数 |

### SSH 报错对照

| 报错 | 可能原因 |
|------|----------|
| `Connection timed out` | 安全组未放行 22、IP 错误、网络不通 |
| `Connection refused` | SSH 服务未启动 |
| `Connection aborted` | 代理（如 Mihomo）干扰、fail2ban、防火墙重置 |
